# 📍 Virtual GEO

**Виртуальная геолокация для браузера** — задайте свои координаты для любых сайтов.

[![Version](https://img.shields.io/badge/version-2.2-green)](https://github.com/vitalibkru/virtual-geo/releases)
[![License](https://img.shields.io/badge/license-MIT-blue)](LICENSE)

---

## 🌟 Возможности

- ✅ **Задайте любые координаты** — широта, долгота, точность, высота
- ✅ **Работает на всех сайтах** — Google Maps, Яндекс.Карты, социальные сети
- ✅ **Два режима работы** — обычный и режим отладки (для сложных сайтов)
- ✅ **Автоматическое обновление** — координаты применяются мгновенно
- ✅ **Полная приватность** — все данные хранятся только в вашем браузере

---

## 📦 Установка

### Вариант 1: Ручная установка (для разработчиков)

1. Скачайте [последний релиз](https://github.com/vitalibkru/virtual-geo/releases)
2. Распакуйте архив
3. Откройте `chrome://extensions/`
4. Включите **"Режим разработчика"** (справа вверху)
5. Нажмите **"Загрузить распакованное расширение"**
6. Выберите папку с расширением

---

## 🚀 Как использовать

1. **Нажмите на иконку расширения** в панели браузера
2. **Введите координаты**:
   - Широта (Latitude)
   - Долгота (Longitude)
   - Точность (Accuracy)
   - Высота (Altitude) — опционально
3. **Нажмите "Сохранить"**
4. **Проверьте** на [browserleaks.com/geo](https://browserleaks.com/geo)

### Режим отладки

Если на каком-то сайте координаты не подменяются:
1. Включите **"Режим отладки"** в настройках
2. Chrome покажет предупреждение — это нормально
3. Теперь расширение работает на уровне браузера (100% надёжность)
