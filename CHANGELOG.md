## 🎉 Virtual GEO v1.0 — Первый релиз!

Первая публичная версия расширения **Virtual GEO** — инструмента для задания виртуальной геолокации в браузере.

### ✨ Возможности

- **Виртуальная геолокация** — задайте любые координаты для всех сайтов
- **Гибкие настройки**:
  - Широта и долгота
  - Точность определения (в метрах)
  - Высота над уровнем моря
  - Точность высоты
- **Два режима работы**:
  - 🟢 **Обычный** — JS-подмена, без предупреждений браузера
  - 🔧 **Режим отладки** — через Chrome DevTools Protocol, максимальная надёжность
- **Мгновенное применение** — координаты обновляются на лету без перезагрузки страницы
- **Тестовая кнопка** — быстрая проверка на [browserleaks.com/geo](https://browserleaks.com/geo)
- **Работа с iframe** — подмена работает во всех фреймах страницы

### 🔒 Приватность

- ✅ Все настройки хранятся **локально** в браузере (`chrome.storage.local`)
- ✅ Нет сбора, передачи или анализа данных
- ✅ Нет связи с внешними серверами
- ✅ Открытый исходный код — можно проверить

### 📦 Установка

**Ручная установка (для разработчиков):**

1. Скачайте `VirtualGEO.zip` из раздела **Assets** ниже
2. Распакуйте архив в любую папку
3. Откройте `chrome://extensions/`
4. Включите **"Режим разработчика"** (справа вверху)
5. Нажмите **"Загрузить распакованное расширение"**
6. Выберите папку с распакованными файлами
