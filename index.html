Privacy Policy

Virtual GEO Browser Extension

Last updated: June 30, 2026

1. Overview

Virtual GEO is a browser extension that allows users to set custom virtual geolocation coordinates for websites. This privacy policy explains what data the extension handles and how it is processed.

TL;DR: We don't collect, transmit, or share ANY data. Everything stays on your device.

2. Data Collection

Virtual GEO does NOT collect, transmit, or share any user data.

The extension does not:

  • Collect personal information (name, email, IP address, etc.)
  • Track browsing history or visited websites
  • Send any data to external servers
  • Use analytics or telemetry
  • Share data with third parties
  • Use cookies or similar tracking technologies

3. Data Storage

All user settings are stored locally in the browser using chrome.storage.local. This includes:

  • Custom geolocation coordinates (latitude, longitude)
  • Accuracy, altitude, and altitude accuracy values
  • Debug mode preference

This data never leaves the user's device and is accessible only to the extension itself.

4. Permissions Explained

The extension requests the following permissions, all required for its core functionality:

  • storage — to save user settings locally.
  • tabs — to apply geolocation overrides to open tabs.
  • scripting — to inject the geolocation override script into web pages.
  • debugger — optional "Debug mode" that uses Chrome DevTools Protocol for reliable geolocation override on complex websites.
  • <all_urls> — to override geolocation on any website the user visits.

5. How It Works

When a website requests the user's geolocation via the browser's Geolocation API, Virtual GEO intercepts this request and returns the coordinates configured by the user. No data is sent to any server — the override happens entirely within the user's browser.

In "Debug mode", the extension uses Chrome DevTools Protocol (CDP) to override geolocation at the browser level, providing maximum compatibility with complex websites.

6. Third-Party Services

The extension does not integrate with any third-party services, analytics platforms, advertising networks, or external APIs.

7. Children's Privacy

The extension does not knowingly collect any data from anyone, including children under the age of 13. Our service is designed to respect user privacy regardless of age.

8. Security

Since we don't collect or transmit any data, there's no risk of data breaches or unauthorized access to user information. All data remains securely stored in the user's browser.

9. Changes to This Policy

We may update this Privacy Policy from time to time. Any changes will be posted on this page with an updated revision date. We encourage users to review this policy periodically.

10. Contact

If you have any questions about this Privacy Policy or the extension itself, please:
